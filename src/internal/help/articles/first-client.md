Клиент прокси — это устройство, адрес, сеть или именованная группа сетей,
которые описаны в разделе «Клиенты». Машина, не описанная как клиент,
получает отказ: доступ закрыт по умолчанию.

## Адрес и порт прокси

Адрес и порт подключения показаны в шапке панели состояния. Для подключения
без логина используется HTTP-слушатель, для подключения с логином — TLS.
Конкретные значения задаёт установка; менять listener-порты через панель
и API нельзя.

## Создание клиента

В разделе «Клиенты» нажмите «Новый клиент». Задайте:

- **Имя** — латиница, цифры и дефис; под этим именем клиент виден в журнале.
- **Тип** — устройство, сеть или группа; это метка для людей, доступ
  определяется адресами ниже.
- **Адреса источника** — IP/CIDR, которые видит Squid. Обычно точный адрес
  `/32` или `/128`; для группы — CIDR. Пересечения между включёнными
  клиентами запрещены.
- **Доступ** — список доменов, весь веб или пока без доступа.
- **Подключение** — HTTP без логина или TLS с логином прокси.

## Доступ

Режим доступа — свойство клиента:

- **Список доменов** — свои домены клиента и подключённые политики. Политика —
  именованный набор доменов; одну и ту же политику подключают нескольким
  клиентам, у клиента их может быть сколько угодно. Открыто объединение;
  вкладка «Доступ» показывает итоговый список и откуда взята каждая строка.
  Пустой список означает отсутствие разрешённых ресурсов, а не весь интернет.
- **Весь веб** — внешние HTTP/HTTPS на разрешённых web-портах (80/443 и
  CONNECT на 443) с защитными запретами.
- **Нет доступа** — клиент описан, все запросы получают отказ.

Защитные запреты (loopback, link-local, metadata, private, опасные порты)
действуют в любом режиме и не отменяются доступом клиента. См.
[Закрыто по умолчанию и защитные запреты](help:how-default-deny).

## Применение

Клиент и политика попадают в черновик. Чтобы запросы пошли — проверьте и
примените черновик, см. [Черновик, проверка и применение](help:draft-apply).
После применения машина, описанная как клиент, выходит через прокси;
неописанная — получает отказ.
