# Изменения проекта

Сначала прочитайте [AGENTS.md](AGENTS.md) и [маршрут документации](docs/README.md).
Сейчас проект находится на этапе архитектуры. Не считать proposed stack и API
готовой реализацией. Сложную задачу оформляйте через task/execution-plan template.

Для документации достаточно `make check`. При появлении кода добавьте реальные
команды, meaningful tests и обновите контракт. Не коммитьте private keys, `.env`,
реальные access logs, SQLite и персональные данные инфраструктуры.

PR описывает проблему, итоговое поведение, проверки и ограничения. Решения о
границах доверия, TLS, хранении и применении конфигов сопровождаются ADR.
Реальные владельцы review, remote и условия лицензирования пока не назначены.
