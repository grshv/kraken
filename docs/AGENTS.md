# Область docs/

Различайте требования, предложения, реализацию и подтверждённые измерения.
У каждого ADR есть статус. Новый факт из внешнего источника сопровождается
первичной ссылкой и датой проверки; inference отмечается как наше решение.
Проверка после изменений: `make docs-check` из корня репозитория.
Не превращайте будущие runbook-команды в якобы существующие без реализации.
