# ADR 0019: база Alpine и Squid из upstream-релиза

Дата: 2026-10-29. Статус: Accepted по решениям владельца 29.10.2026
([decisions](../product/decisions.md), пункты «Продукт и развёртывание» и
«Безопасность и доступ»).

Заменяет базу образа из [ADR 0006](0006-single-container.md) (pinned
`ubuntu/squid`); остальное в ADR 0006 действует.

## Контекст

Образ `ubuntu/squid:6.6-24.04_beta` содержал Squid 6.13: ветка 6 закрыта upstream,
тег Canonical не совпадает с версией внутри. Образ `ubuntu/squid` для 26.04
есть только в канале edge и собран chiseled, без утилит, на которые опираются
сборка образа и запуск панели. Alpine и Ubuntu в своих архивах отстают от
последнего релиза Squid. Образ на Ubuntu весит около 220–330 MB, на Alpine — около 40 MB.

## Решение

- Runtime-база — `alpine` текущей стабильной ветки, закреплённая digest.
- Squid собирается в отдельной стадии из tarball последнего стабильного релиза
  `squid-cache/squid` на GitHub; версия и sha256 tarball закреплены в Dockerfile.
  Исходники не патчатся, возможности не отключаются: `configure` получает только
  пути установки, `--with-openssl`, пользователя по умолчанию и
  `--disable-strict-error-checking` (иначе новые предупреждения компилятора
  останавливают сборку). Компилятор и заголовки в runtime не попадают.
- Обновление Squid — смена версии и sha256 в Dockerfile, пересборка и полный
  `make integration`.
- Root внутри контейнера остаётся только у Pebble, чтобы запускать Squid (`proxy`
  13:13) и панель (`kraken` 10013:10013) под разными UID по
  [ADR 0015](0015-separate-squid-uid.md). Контейнер получает только capabilities
  `SETUID`, `SETGID`, `KILL`; `no-new-privileges` включён.

## Альтернативы

- Ubuntu 26.04 и пакет `squid` из архива: Squid сразу актуален, но образ в
  несколько раз больше, а версия зависит от SRU Canonical.
- Chiseled `ubuntu/squid` 26.04: только канал edge и нет утилит для запуска панели.
- Пакет Squid Alpine: отстаёт от upstream на минорный релиз.
- Один UID без root: отменяет ADR 0015, компрометация Squid даёт доступ к БД
  и ключам панели.

## Последствия

- Обновления безопасности Squid отслеживаются по релизам upstream, а не через
  дистрибутив; остальные пакеты runtime — через пересборку на свежем digest Alpine.
- musl вместо glibc; совместимость проверяет `make integration` на реальном образе.
- Сборка Squid добавляет несколько минут к холодной сборке образа; слой кешируется.
