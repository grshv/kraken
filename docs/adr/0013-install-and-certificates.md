# ADR 0013: установка без ручных шагов и CA установки

Статус: Accepted. Дата: 2026-11-02.

## Контекст

Каталог хоста вместо тома (`./data:/var/lib/kraken`) перекрывал раскладку образа,
а root без capabilities не мог передать его UID 10013 и 13. Без сертификатов панель
уходила в цикл перезапусков. Самоподписанный leaf только для `localhost` нельзя
было импортировать как CA, а HSTS с `includeSubDomains; preload` не давал открыть
панель после предупреждения браузера.

## Решение

- PID 1 — `kraken entrypoint` от root, затем `exec` Pebble. Корень тома
  `10013:13 0750` считается готовым. Иначе entrypoint с `CAP_CHOWN` создаёт `data/`,
  `certs/`, `log/` и раздаёт владельцев по [ADR 0009](0009-separate-squid-uid.md).
  Каталог с посторонними именами, symlink, hard link или специальными файлами
  отклоняется без изменений. `DAC_OVERRIDE` и `FOWNER` не добавляются.
- Без сертификатов `serve` выпускает CA установки (ECDSA P-256, 10 лет,
  `pathlen 0`, критичные name constraints только на имена установки) и подписанные
  им сертификаты панели и TLS-прокси (397 дней, `serverAuth`). Имена — `localhost`,
  host из `KRAKEN_PUBLIC_ORIGIN`, адреса публикации и `KRAKEN_CERT_NAMES`.
  Неполный набор файлов — ошибка, а не перезапись.
- Свой сертификат ставит `kraken cert install panel|proxy`: сертификат и ключ одним
  PEM через stdin; команда проверяет пару, срок, `serverAuth`, SAN и выставляет права.
- TLS-listener прокси 3129 включён и опубликован по умолчанию.
- HSTS — `max-age=31536000` без `includeSubDomains` и `preload`.
- Сеть — bridge. Несколько адресов хоста — дополнительные `ports` в
  `compose.override.yaml`.

## Альтернативы

- Сообщение с командой `chown` для хоста: быстрый старт снова требует ручного шага.
- CA без ключа на томе: любое продление требует нового импорта; name constraints
  делают хранение ключа безопасным.
- Host network: настоящий source IP без override, но контейнер теряет сетевую
  изоляцию, а служебные listeners Squid попадают на loopback хоста.

## Последствия

- Root PID 1 меняет владельцев только на время подготовки и только в каталоге с
  раскладкой Kraken.
- Доверие к панели и прокси — один импорт `ca.crt` (`kraken cert ca`). Имя вне
  constraints при `kraken cert renew` создаёт новый CA, его нужно импортировать заново.
