# ADR 0004: клиенты прокси и expert-секция с allowlist

Статус: Accepted. Дата: 2026-10-27.

## Контекст

Клиент прокси — устройство, сервер, контейнер, адрес, сеть или группа; VM — только
пример. Визуальной модели достаточно для типичных задач, но администратору нужен
аварийный выход в squid.conf. Denylist директив оказался неполным: на Squid
`err_page_stylesheet <файл>` вставлял содержимое файла (например, TLS-ключа) в
страницу ошибки, видимую клиентам.

## Решение

- Клиента определяет source IP, который видит Squid, или логин прокси
  ([ADR 0008](0008-proxy-logins.md)). Тип host/network/group — подпись для UI.
- Визуальные настройки и expert-секция существуют вместе. В режиме expert секция
  заменяет визуальные правила доступа; они сохраняются и не действуют.
- Защитные `http_access deny` (опасные порты, manager, внутренние адреса,
  «запрещено для всех») рендерятся до пользовательского блока в любом режиме.
- Expert-секция принимает только директивы из allowlist (`expertDirectives` в
  `internal/policy/settings.go`): правила доступа, cache и refresh, `cache_peer`,
  заголовки запроса, DNS, таймауты, лимиты, delay pools, `if/else/endif`.
  Дополнительно:
  - параметры из файлов (`"/…"`, `parameters(…)`) запрещены;
  - `deny_info` — только `ERR_*`, `http(s)://` URL (с кодом 30x) или `TCP_RESET`;
  - `cache_peer` — только IP-литерал вне защищённых сетей; private-адрес — только
    при `allow_private_destinations`; опции-пути запрещены;
  - имена с префиксом `sc_` зарезервированы за рендером.
- Listeners, пути, helpers, include, смена UID, `cache_dir` и manager закрыты.
  Listener-порты принадлежат установке: черновик и старая ревизия их не меняют.
- Ошибка `squid -k parse` возвращает только номер строки, без вывода Squid.

## Последствия

- Расширение allowlist — изменение границы: директива добавляется с тестом и
  проверкой, что она не читает файлы, не открывает listener и не запускает процесс.
- `cache_peer` меняет маршрут трафика за пределами визуальной модели; egress
  firewall остаётся обязательным.
- Клиенты с логином прокси не совмещаются с expert-режимом.
