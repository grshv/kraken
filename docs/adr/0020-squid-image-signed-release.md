# ADR 0020: Squid отдельным образом, релиз проверяется подписью

Дата: 2026-11-01. Статус: Accepted по решению владельца 01.11.2026
([decisions](../product/decisions.md), «Продукт и развёртывание»).

Заменяет в [ADR 0019](0019-alpine-upstream-squid.md) сборку Squid стадией
образа панели и проверку tarball по закреплённому sha256; остальное в ADR 0019
действует.

## Контекст

Squid компилировался в каждой сборке образа панели (около 10 минут на раннер
GitHub), хотя меняется только с версией. Версия и sha256 tarball правились
вручную: бот обновлений не может посчитать хеш нового архива. Сканирование
уязвимостей Squid было привязано к сборке панели.

## Решение

- Squid собирается отдельным образом `ghcr.io/grshv/kraken-squid:<версия>`
  (`deploy/squid`, amd64 и arm64) только при изменении `deploy/squid`. Образ —
  `scratch` с установленным деревом; `configure` прежний (ADR 0019).
- Tarball принимается только с подписью ключей релизов Squid из
  `deploy/squid/squid-keys.asc` (`gpgv` с этим и только этим набором ключей).
  Набор ключей — доверенный корень вместо хеша; меняется отдельным коммитом с
  проверкой отпечатков по squid-cache.org.
- Версия задаётся тегом релиза (`ARG SQUID_TAG=SQUID_<major>_<minor>`); Renovate
  предлагает новую версию по релизам `squid-cache/squid`.
- Образ панели берёт Squid из `ARG SQUID_IMAGE`, закреплённого digest; Renovate
  обновляет ссылку после публикации нового образа Squid. Локально
  `make squid-image` и `make image SQUID_IMAGE=kraken-squid:local`.

## Альтернативы

- Стадия в общем Dockerfile с кэшем слоёв: Squid пересобирается при любом
  промахе кэша, а версия и sha256 по-прежнему правятся вручную.
- Пакет Squid Alpine: отстаёт от upstream (ADR 0019).
- Хеш, опубликованный рядом с архивом: приходит из того же источника, что и
  архив, и не защищает от подмены релиза.

## Последствия

- Компрометация ключа релизов Squid позволяет подписать подменённый архив;
  смена набора ключей — явный коммит.
- Образ панели собирается без компиляции Squid; обновление Squid — два шага:
  публикация `kraken-squid`, затем смена digest в `deploy/Dockerfile` с
  `make integration`.
- Squid и панель собраны на одном релизе Alpine; смену digest Alpine в обоих
  Dockerfile Renovate предлагает одним PR.
