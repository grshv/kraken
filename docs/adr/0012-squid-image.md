# ADR 0012: Squid из подписанного upstream-релиза

Статус: Accepted. Дата: 2026-11-01.

## Контекст

Образы `ubuntu/squid` отставали от upstream (тег `6.6-24.04` содержал закрытую
ветку 6.13) или были доступны только в канале edge без утилит запуска. Пакеты Alpine
и Ubuntu тоже отстают. Компиляция Squid в каждой сборке панели занимала около
10 минут, а версию и sha256 архива приходилось править вручную.

## Решение

- База образа — Alpine текущей стабильной ветки, закреплённая digest.
- Squid собирается отдельным образом `ghcr.io/grshv/kraken-squid:<версия>`
  (`deploy/squid`, amd64 и arm64) из tarball последнего стабильного релиза
  `squid-cache/squid` только при изменении `deploy/squid`.
- Архив принимается только с подписью ключей релизов Squid из
  `deploy/squid/squid-keys.asc` (`gpgv` только с этим набором). Набор ключей меняется
  отдельным коммитом с проверкой отпечатков по squid-cache.org.
- Исходники не патчатся, возможности не отключаются: `configure` получает только
  пути установки, `--with-openssl`, `--with-default-user=proxy` и
  `--disable-strict-error-checking` (иначе предупреждения нового компилятора
  останавливают сборку).
- Образ панели берёт Squid по закреплённому digest и принимает его только с
  provenance attestation от `squid.yml`. Renovate предлагает новую версию Squid и
  затем новый digest.
- Идентичность образа — ссылки Alpine и Squid из `deploy/Dockerfile`, вшитые в
  бинарник; откат ревизии возможен только на том образе, где она применялась.

## Альтернативы

- Пакет Squid Ubuntu 26.04: актуален, но образ в несколько раз больше, а версия
  зависит от SRU Canonical.
- Стадия в общем Dockerfile с кешем слоёв: Squid пересобирается при любом промахе
  кеша, версия и хеш правятся вручную.
- Хеш, опубликованный рядом с архивом: приходит из того же источника и не защищает
  от подмены релиза.

## Последствия

- Обновления безопасности Squid отслеживаются по релизам upstream; остальные пакеты —
  пересборкой на свежем digest Alpine. SBOM получает Squid по CPE.
- musl вместо glibc; совместимость проверяет `make integration` на реальном образе.
- Компрометация ключа релизов Squid позволяет подписать подменённый архив.
