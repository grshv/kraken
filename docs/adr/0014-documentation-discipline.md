# ADR 0014: документация для агентской разработки

Дата: 2026-10-29. Статус: Accepted по поручению владельца навести порядок в документации.

## Контекст

По ADR 0005 появились root и вложенные AGENTS, карта docs, шаблоны задач/планов/handoff,
архив завершённых планов и capability report. На практике агенты дописывали отчёты
о сессиях в конец спецификаций, статус «реализовано» расходился в пяти документах,
шаблоны и вложенные инструкции не использовались, а проверка не ловила расхождений.

## Решение

- Одна инструкция агентам — корневой `AGENTS.md` с таблицей «что меняется → какой
  документ обновить» и критериями готовности.
- Статус реализации и проверок — только в `docs/status.md`.
- Документы описывают текущее состояние; история — в git log. Архив планов,
  шаблоны и процессные документы удалены.
- `make docs-check` механически проверяет правила: реестр ADR совпадает со статусами
  файлов, каждый документ в `docs/` доступен из карты, в описательных документах нет
  заголовков с датами, вложенных AGENTS.md нет.

## Последствия

Меньше документов и одно место для статуса. Механическая проверка не гарантирует
смысловую актуальность: ревью по-прежнему сверяет diff кода с таблицей обновлений.
